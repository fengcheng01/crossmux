墨菲 M4 固件全新 UI 设计原型

4.26" · 800×480 · 219 PPI · 墨韵极简 (InkCraft)

设计审查与对比分析 墨菲 M4

1. 纸面，不是贴纸 ★

UI 在固件里是 1-bit。去掉 2px 投影、1.5px 双边和 900 字重。一张卡一条 1px 墨线，层级靠字号和留白，不靠阴影堆砌。

2. 选中不再整块涂黑

文件夹用加粗描边 + 角标；应用只反色图标本身并在名称下划线。整卡填黑在 4.26" 上看起来像坏点。

3. 主页只做「接着读」

去掉无动作的鸡汤条。主卡整张可点继续阅读，下面两本最近书。简报数字与统计页同一套数据。

4. 对得上固件

底栏顺序：书架 · 应用 · 主页 · 设置 · 统计。抗锯齿文案用关 / 叠加 / 合成 / 直刷 / 快刷。侧键是电源、上、下，不是音量。
